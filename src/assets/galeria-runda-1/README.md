# Zdjęcia rundy pierwszej

Wrzuć pliki JPG lub JPEG bezpośrednio do tego folderu. Po zapisaniu zmian na gałęzi main i zakończeniu wdrożenia pojawią się automatycznie w galerii pod tabelą na stronie Raport. Kolejność zależy od nazw plików, np. 01.jpg, 02.jpg, 03.jpg. Nie umieszczaj zdjęć w podfolderach.
